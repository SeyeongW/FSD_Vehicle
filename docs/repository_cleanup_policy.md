# Repository Cleanup Policy

The Waver workspace is a field-release ROS 2 workspace. Cleanup must be
conservative: remove generated artifacts only when the command explicitly asks
for it, and never delete source-like files just because they look old.

## Categories

- `SOURCE_REQUIRED`: source code, launch files, package manifests, config, tests.
- `FIELD_RELEASE_REQUIRED`: scripts, configs, docs, and tests required by the
  real Waver field release.
- `LOCAL_RUNTIME_REQUIRED`: local operator scripts, env examples, and field
  bridge scripts required for PC -> SSH -> Jetson Docker -> Waver operation.
- `GENERATED_ARTIFACT`: build outputs, Python caches, colcon logs, rosbag files,
  and runtime databases.
- `GENERATED_REPORT`: reports generated by checkers or smoke tests.
- `SIM_EVIDENCE`: Gazebo smoke reports or simulation traces kept as evidence.
- `LEGACY_BUT_REFERENCED`: older scripts or docs still referenced by code/tests.
- `LEGACY_DEPRECATED`: old scripts that are not part of the field release.
- `PRIVATE_LOCAL_CONFIG`: ignored operator-local files such as passwords or
  machine-specific IP overrides.
- `VENDOR_OR_SUBMODULE`: third-party code such as Livox vendor drivers.
- `EXCLUDE_FROM_RELEASE`: local bags, experiment results, large outputs, and
  generated data that must not ship in a source release.
- `CANDIDATE_FOR_ARCHIVE`: human-reviewed files that may be archived later but
  must not be automatically removed.

## Non-Negotiable Preserve List

These field bridge scripts must never be automatic cleanup candidates:

- `scripts/waver_field_docker_backend_start.sh`
- `scripts/waver_field_local_ui_start.sh`
- `scripts/waver_field_lidar_nav_backend_start.sh`
- `scripts/waver_start_field_backend.sh`

## Allowed Automatic Cleanup

`scripts/waver_conservative_cleanup_plan.py --apply` may only remove generated
artifacts such as:

- `build/`
- `install/`
- `log/`
- `.pytest_cache/`
- `__pycache__/`

It must not remove `src/`, `scripts/`, `config/`, `docs/`, `README*`, vendor
drivers, field bridge scripts, or local private config files.

## Required Workflow

1. Generate inventory:

   ```bash
   python3 scripts/waver_worktree_inventory.py
   ```

2. Generate cleanup plan:

   ```bash
   python3 scripts/waver_conservative_cleanup_plan.py --dry-run
   ```

3. Review `reports/cleanup_plan.md`.

4. Only if generated artifact removal is intended:

   ```bash
   python3 scripts/waver_conservative_cleanup_plan.py --apply
   ```
