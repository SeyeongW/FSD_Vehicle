# 실험 및 성능평가

## 1. 실험 시나리오 설계

표적(새)의 회피 기동을 재현하기 위해 불규칙 방향전환과 물리적으로 타당한 선회율 제한이 있는 비행 패턴을 실험 시나리오로 설계했다. 표적은 최대 비행속도 1.2 m/s, 최대 선회율 120°/s 이내에서 임의의 방향전환을 반복하며 회피 기동을 모사한다. 로봇은 20 m × 20 m 시뮬레이션 맵에서 3-LiDAR 융합 기반 탐지·추적 결과를 입력으로 받아 추격 제어를 수행하며, 표적이 최초 검출되면 순찰을 멈추고 추적 모드로 전환해 이후 일정 시간 동안 추격 성능을 기록한다.

## 2. 추격 제어 3자 비교 실험

### 왜 이 세 가지 방법을 선정했는가

본 연구는 계산량이 적고 이동표적 요격에 직접 대응하는 유도법칙(PN, Pure Pursuit)과, 표적 기동을 유계 외란으로 간주해 강인하게 대응하는 SMC를 조향 후보로 선정했다. PN의 변형인 APN·TPN은 PN의 미분 의존 약점을 그대로 공유하고, LQR은 선형화 근방에서만 안정성이 보장돼 급기동에 부적합해 이번 비교에서 제외했다.

### 비교 방법 및 평가지표

세 조향 법칙(PN, Pure Pursuit, SMC)을 동일 조건에서 비교하기 위해 각 방식마다 동일한 표적 비행 모델로 3회씩 반복 실험했다(총 9회). 세 방식 모두 동일 세션에서 동일 표적 비행 모델로 재실측했다 — 표적 비행 모델이 이전 검증 단계 이후 갱신되어, 기존 PN·Pure Pursuit 데이터를 재사용하지 않고 전량 재실측함으로써 동일 조건 비교를 보장했다. 평가지표는 Table 7과 같이 세 가지를 사용했다.

**Table 7.** Evaluation metrics for pursuit control comparison

| 지표 | 정의 | 방향성 |
|---|---|---|
| 평균 거리 (m) | 추적 모드 구간에서 로봇-표적 간 수평거리의 평균 | 낮을수록 우수 (근접 추격) |
| 2.5 m 이내 유지율 (%) | 추적 모드 구간 중 거리가 2.5 m 이내로 유지된 시간 비율 | 높을수록 우수 |
| 조향각속도 변동성 (°/s) | 로봇 요(yaw) 각속도의 표준편차 | 낮을수록 우수 (부드러운 조향, 채터링 확인용) |

### 결과 분석 및 SMC 채택

Pure Pursuit는 평균 거리·근접 유지율 모두 최저에 회차 간 편차도 가장 커(2.5 m 이내 유지율 표준편차 12.7%p, 나머지 두 방식의 4배 이상) 세 방식 중 가장 열세였다. SMC와 PN은 경쟁 구도로, SMC는 평균 거리·조향 부드러움·반복 재현성에서 우위였고 PN은 2.5 m 이내 유지율에서 앞섰는데, 구동계 부담(급격한 각속도 변화로 인한 저크)과 재현성을 함께 고려해 **본 연구에서는 SMC를 최종 추격 제어기로 채택**했다.

## 3. SMC 원리 및 적용 방법

슬라이딩 모드 제어(SMC)는 시스템 상태를 설계한 슬라이딩 면 s=0 위로 유한시간 내에 올린 뒤 그 위에 묶어두어, 외란·모델 불확실성에도 강인성을 보장하는 비선형 제어기법이다[n]. 고전(1차) SMC는 불연속 스위칭 k·sign(s)로 구현돼 s=0 근방에서 채터링(고주파 진동)이 발생하며, 이를 완화하는 경계층(tanh) 근사는 채터링을 정상상태 오차와 맞바꾸는 절충일 뿐이다. 본 연구는 불연속성을 적분항에만 두어 제어 입력 자체는 연속으로 유지하면서도 s=0으로의 유한시간 수렴을 이론적으로 보장하는 2차 슬라이딩 모드 기법, Super-Twisting Algorithm(STA)[n]을 채택했다.

PN 열세의 핵심 원인이 시선각 변화율(λ̇)의 미분 의존이었다는 점에 착안해, 미분이 필요 없는 1차 항인 로봇 기준 표적 방위각(β) 자체를 슬라이딩 면으로 삼았다(식 1). 제어 법칙은 정칙화된 STA(식 2)를 사용했다. 원래 STA의 비례항(sqrt(|s|)·sign(s))은 s=0 근방에서 기울기가 발산해 작은 오차에도 과민 반응하므로, 분모에 ε을 더해 정칙화했다. u₁은 적분(스위칭) 항으로 식 (3)처럼 갱신하되, 이미 최대각속도로 포화된 상태에서 sign(s)가 그 방향을 더 키우면 적분을 멈추는 안티와인드업(조건부 적분)을 적용했다. |s| < δb(정렬 완료)이면 비례항을 끄고 u₁도 매 스텝 0.8배씩 감쇠시켜, 작은 오차에서도 적분이 쌓여 과회전하는 문제를 완화했다. 식 (2)의 −k_d·ω_r(실측 각속도 감쇠, `/odom` 기반)은 순수 STA 이론에는 없는 항으로, 회전 관성이 계속 이어지는 것을 억제하는 실장 보정이다 — 따라서 본 연구의 SMC는 엄밀히는 STA와 각속도 감쇠의 하이브리드다.

```
(1)   s = beta
```

```
(2)   omega_{SMC} = k_1 cdot {s} over {sqrt{|s| + epsilon}} + u_1 - k_d cdot omega_r
```

```
(3)   u_1(t+Delta t) = u_1(t) + k_2 cdot "sign"(s) cdot Delta t
```

Table 10은 사용한 파라미터 값이다.

**Table 10.** SMC (Super-Twisting) parameters

| 기호 | 값 | 의미 |
|---|---|---|
| k₁ | 1.5 | 비례항 게인 |
| k₂ | 0.2 | 적분(스위칭) 게인 |
| ε | 0.05 | 정칙화 상수 |
| δb | 0.05 rad | 정렬 데드밴드 |
| u₁ 상한 | 1.0 rad/s | 적분항 자체 포화 한계 |
| k_d | 1.0 | 각속도 감쇠 게인 |

## 4. 시스템 동작 검증

채택된 SMC 조향으로 실제 추격이 설계대로 동작하는지 RViz2 화면으로 확인했다. Fig. 7은 추적 중 표적(초록)과 로봇(빨강)의 실주행 경로를 나타낸다. 표적이 급격히 방향을 바꾸는 구간에서도 로봇이 근접한 경로로 따라붙는 것을 확인할 수 있으며, 로봇 경로가 표적 경로보다 상대적으로 매끄럽게 이어지는 것은 SMC 조향의 낮은 조향각속도 변동성(Table 8)과 일치하는 결과다. 화면 우측 상단의 파란 상자는 해당 시점에 검출된 표적 클러스터의 바운딩박스다.
