# KCI 논문 아웃라인 (개정판)

> 작성일: 2026-07-29 (개정). 해커톤(2026-09) 산출물을 논문 데이터로 겸용하는 것을 전제로 함. 마감: 2026-11 이전.
> **2026-07-29 스코프 확정**: 맵 크기(100x100 등)·LiDAR 반경(200m)·로봇 동역학 재설계 **전부 업그레이드 안 함 — 해커톤에서 만든 것 그대로 사용.** 대신 추격 제어기를 PN/PP 2자 비교에서 **SMC를 추가한 3자 비교**로 확장하는 쪽으로 논문 핵심을 잡음.

## 가제
"분산 다중 LiDAR 기반 조류 탐지·추적 및 자율 이동로봇 추격 제어기 성능평가"

## 핵심 기여 (3가지)
1. 좌표계 순환의존(map/odom) 문제를 회피하는 odom 프레임 기반 다중 LiDAR 융합 + 탐지·추적(DBSCAN+KF) 아키텍처
2. Nav2 범용 스택 대신 정적 환경 특화 커스텀 순찰 제어(atan2 P-D)로 튜닝 상호간섭 문제 해결
3. **추격 유도/제어법칙 3자 비교: PN vs Pure Pursuit vs SMC(슬라이딩 모드 제어)** (핵심 실험)
   - 해커톤: 이론상 PN이 유리할 것이라는 가설을 구현·3회 반복실험으로 검증했으나 반증(Pure Pursuit 채택), 원인은 LOS rate 미분의 노이즈 증폭 + 비동기 저속 탐지
   - KCI 확장: PN의 실패 원인(미분 의존, 예측 필요)을 이론적으로 정면 대응하는 강인제어(SMC)를 새로 구현해 PP와 재비교. DWA/MPC/APN/TPN/LQR 등 다른 대안은 검토 후 이유를 들어 기각(아래 3.7 참고)

**참고**: 로봇 동역학 모델링(질량/관성/모터모델)은 대규모 맵 스케일업 계획과 함께 스코프 아웃됨 — 이번 논문에서는 다루지 않음.

## 1. 서론
- 군 공항 조류충돌(Bird Strike) 위험성 및 피해 통계
- 기존 대응(인력 순�찰, 음향 퇴치, 단일 센서)의 사각지대/한계
- 제안: 분산 LiDAR(고정 2대+온보드 1대) + PTZ 카메라 검증 + 자율 이동로봇 추격
- 본 논문의 기여 3가지 (위 목록)
- 논문 구성 안내

## 2. 관련 연구
- LiDAR/레이더/비전 기반 조류·소형 비행체 탐지 연구
- 이동로봇 추격 유도법칙: Pure Pursuit, 비례항법(PN, 원 미사일 유도이론), 슬라이딩 모드 제어(SMC)
- 다중 센서 융합 기반 감시/순찰 로봇 시스템

## 3. 시스템 설계
3.1 전체 아키텍처 개요 (파이프라인 다이어그램: 융합→탐지/추적→상태기계→순찰/추격)
3.2 좌표계 통합 및 포인트클라우드 융합 — **왜 map이 아닌 odom인지** (AMCL map→odom과 자체 world→odom 충돌 문제, 순환의존 문제)
3.3 조류 탐지·추적: DBSCAN 클러스터링 + Kalman Filter, stale 프레임 스킵(coast-only) 처리
3.4 상태기계: PATROL ↔ TRACKING 전환
3.5 순찰 제어: atan2 기반 P-D 커스텀 컨트롤러 (Nav2 전체 스택 대비 설계 이유 — TEB/velocity_smoother 상호 clamp로 인한 튜닝 불가 문제)
3.6 추격 제어 후보 세 가지
   - **Pure Pursuit**: 방위각 기반 비례 조향, 미분 없음
   - **PN 비례항법**: LOS rate 기반 (λ̇, ω=N·λ̇), 교착방지 보정항 K_b·β 포함
   - **SMC (슬라이딩 모드 제어)**: 슬라이딩 면 s=e_θ(방위각 오차, 미분 미사용 — 노이즈 민감성을 피하려 1차 슬라이딩 면으로 설계), 제어법칙 ω=u_eq - K·tanh(s/φ) (경계층 근사로 채터링 완화)
3.7 **고려했으나 기각한 대안 제어기법 및 사유**
   | 후보 | 기각 사유 |
   |---|---|
   | DWA | 정적/저속 목표+장애물회피용 설계라 이동표적 요격 문제 자체와 범주가 다름. 기존 TEB 제거 경험과 같은 종류의 다중 레이어 clamp 문제 재발 우려 |
   | MPC | 표적 미래궤적 예측에 성능이 좌우되는데 불규칙 회피기동과 전제가 안 맞음. 실시간 최적화가 이미 CPU 여유 없는 노트북에 부담 |
   | APN | PN의 핵심 약점(미분 의존)을 목표가속도 추정(2차 미분)으로 오히려 악화시킴 — 노이즈 증폭이 PN보다 심함 |
   | TPN | 지상로봇 각속도 명령으로 귀결되면 PPN과 계산이 사실상 동일 — PN과 다른 결과가 나올 이유 없음 |
   | LQR | 연산은 가장 가볍고 유효하나, 선형화 지점 근처에서만 안정성 보장 — 새의 큰 각도 급기동 시 근사가 깨짐. SMC의 외란거부 보장이 이 문제에 더 직접적으로 대응 |
3.8 시뮬레이션 실험 플랫폼
   - 맵: 20m×20m (해커톤 그대로, world명 `Simple_20m_Rover_Bird_Runway`), 벽 높이 2.0m
   - LiDAR: Livox Mid-360 ×3 (고정 2대 + 온보드 1대), raycast 최대거리 70m(고정)/200m(온보드, xacro 기본값 — 실제 하드웨어 스펙 70m와 불일치하는 시뮬레이터 한계로 명시)
   - 표적(새) 모델: 충돌형상 1m×1m×1m 정육면체(등방), 날개폭 상한 가정. **한계로 명시**: 등방 정육면체라 실제 조류의 관측각 의존적 단면적(측면에서는 몸통 크기 수준)보다 낙관적일 수 있음
   - 로봇: UGV_MODEL=ugv_rover (해커톤 그대로, 재설계 없음)

## 4. 실험 및 성능평가
4.1 실험 시나리오 설계: 불규칙 방향전환 + 선회반경 제한이 있는 표적(새) 비행 패턴
4.2 평가지표: 평균 거리, N m 이내 근접 유지 비율, (선택) 경로효율/요격 소요시간
4.3 **실험 1 — PN vs Pure Pursuit vs SMC 3자 비교** (핵심 실험)
   - PN vs PP: 해커톤 3회 반복 데이터 재사용 (`pn_slides_content.md` 슬라이드 9)
   - **SMC: 이번에 새로 구현·검증 필요** (다음 작업)
   - 동일 시나리오·동일 반복횟수로 SMC 실측 추가
4.4 원인 분석
   - PN: 미분(LOS rate) 노이즈 증폭 + 표적 예측가능성 전제 위반
   - SMC: 미분 없이(1차 슬라이딩 면) 방위각 오차만으로 외란(표적 급기동)을 이론적으로 거부 — 노이즈 민감성 문제를 정면 회피. 경계층(tanh) 채터링 완화 적용
   - PP 대비 SMC가 실제로 더 나은지, 혹은 PP 수준에 그치는지는 실측으로 확인 필요(가설 검증 단계)
4.5 (선택, 여유 있으면) **실험 2 — 3-LiDAR 융합 vs 단일 LiDAR**: 탐지 커버리지/오탐률, 혹은 거리별 검출 성공률(LiDAR/비전 유효거리 비교) 곡선

## 5. 결론
- 시스템 요약 및 기여 재확인
- PN이 이론상 매력적이어도 실제 센서·표적 조건에서는 열세일 수 있다는 실증적 시사점
- **SMC 검증 결과에 따라 결론 방향이 갈림**: SMC가 PP를 능가하면 "노이즈 강인 제어기법이 실질적 우위" 주장, SMC도 PP 수준이면 "간단한 휴리스틱(PP)도 이 문제에서 충분히 경쟁력 있다"는 결론으로 — 어느 쪽이든 유효한 논문 기여
- 한계: 시뮬레이션 검증 단계(실물 하드웨어 미검증), 표적 모델 단순화(등방 정육면체), 맵 스케일(20x20m)
- 향후 연구: 실제 활주로 스케일 검증, 로봇 동역학 모델 기반 파라미터 정밀화, 실물 PTZ 카메라 연동, GPU 레이캐스트 기반 라이더 성능 개선
