# 다중 센서 기반 공항 탐지 체계

본 연구에서 제안하는 실제 공항 환경 적용 개념은 Fig. 1과 같이 다중 라이다(LiDAR), 비전 카메라, 지상 이동형 순찰 로봇의 연동 체계로 구성된다.

**Fig. 1.** Multi-sensor operational architecture for airport obstacle detection

단일 라이다 센서만 운용할 경우 시야각(FOV)의 물리적 범주, 수직 센싱 레이어의 제한, 점군(Point Cloud) 밀도의 한계로 인해 광범위한 공간을 정밀하게 탐지하기 어렵고, 특히 조류처럼 크기가 작고 이동성이 높은 객체는 고신뢰성 검출을 달성하기 힘들다. 이를 극복하기 위해 서로 다른 시점에 배치된 다중 라이다의 교차 스캐닝 방식을 적용한다. 두 대의 고정 라이다와 비전 카메라, 세 센서의 탐지 범위가 교차하는 중앙 영역에서는 3중 탐지 중첩(Overlap Zone)이 형성되어 점군 밀도가 증폭되며, 이를 통해 조류와 같은 소형·이동 장애물에 대한 인식 정밀도가 향상된다.

라이다가 추정한 3D 점군 좌표는 카메라 및 순찰 로봇과 실시간으로 연동된다. 라이다가 객체의 초기 3D 위치를 추정해 해당 방향으로 카메라 앵글을 회전시키면, 객체가 화면에 포착되는 시점부터 비전 인식(Vision Recognition) 기반의 정밀 추적 및 시각적 검증으로 전환된다. 동시에 순찰 로봇은 해당 좌표 구역으로 이동해 근접 탐지 및 현장 조치를 수행한다.

실제 적용 대상 환경으로 청주공항을 선정하였으나, 공간 스케일과 실험 환경의 제약으로 실제 규모 대신 Gazebo 시뮬레이션 상에 활주로 맵을 구축한 축소 모형으로 시스템을 구현하였다.

센서 선정에 있어 실제 공항 상용화 시에는 128채널 고밀도 레이어를 갖춘 Ouster OS1 Max와 같은 장거리·고성능 라이다가 이상적인 대안이다. 사고 위험이 집중되는 이착륙 구간을 주요 대상 구역으로 삼아 다중 배치하는 운용을 상정하며, 해당 센서는 데이터시트 기준 최대 500m 센싱 범위와 반사율 10% 수준의 소형 개체에 대해서도 200m의 유효 탐지 거리를 제공해 장거리 탐지에 적합하다. 또한 디지털 스피닝(Digital Spinning) 방식으로 데이터 정밀도 변동이 적고 악천후 시 허위 점군(Frustum Noise) 발생을 억제해 환경 적응성이 우수하다.[출처 필요] 다만 고사양 센서는 대용량 점군 데이터로 인한 연산 부하가 매우 크므로, 본 연구에서는 적은 전송량으로 효율적인 점군 밀도를 확보할 수 있는 비반복 스캐닝(Non-repetitive Scanning) 방식의 Livox Mid-360을 채택하였다.
