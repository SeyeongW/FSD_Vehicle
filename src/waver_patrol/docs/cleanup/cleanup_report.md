## Cleanup Policy

The cleanup is intentionally conservative because this workspace contains real-vehicle bringup code and vendor/upstream-like packages.

Deleted automatically:

- Python `__pycache__` and `.pytest_cache` artifacts when present.

Not deleted automatically:

- `build/`, `install/`, and `log/` are generated artifacts, but they are useful for local verification and are ignored by source archive/git rules.
- `src/livox_ros_driver2`, `src/Livox-SDK2`, `src/ugv_else`, and Gazebo/vendor-like packages are not cleaned blindly.
- Legacy scripts are kept unless a reference audit proves they are unused.
